# ADR-004: Corrections

Статус: принято 09.08.2026

## Контекст

Сообщения MAX и подтвержденные записи могут быть исправлены. Молчаливое
перезаписывание производственной истории делает аналитику и научный датасет
невоспроизводимыми.

## Решение

- Подтвержденный `ProductionEvent` не изменяется без сохранения истории.
- Исправление создает новую ревизию или событие с
  `supersedes_event_id`/`corrects_event_id`.
- Исходное сообщение и его ревизии остаются неизменяемым аудитом.
- Текущее состояние изделия является проекцией последней подтвержденной цепочки.
- Для существующих изменяемых `WorkLogEntries` перед научным использованием
  добавляется отдельный аудит ревизий.
- Удаление подтвержденного факта в будущем означает отмену/замещение, а не
  физическое уничтожение истории.

## Следствия

- Аналитика может быть воспроизведена на заданный момент времени.
- Ошибка оператора исправляется явно и не скрывает первичное решение.
- На этапе 0 существующее поведение редактирования WorkLog не меняется.
